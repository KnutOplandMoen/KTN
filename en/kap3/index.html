The Transport Layer

From simple multiplexing and UDP to reliable TCP, congestion control, and QUIC.

  1. 01Overview

Overview

The big picture

The transport layer bridges the gap between the unreliable network and the applications that demand order and guarantees.

The transport layer is like the difference between sending a postcard and a registered letter. A postcard is quick and cheap — you write it, drop it in the mailbox, and hope it arrives. You never find out whether the recipient got it. A registered letter costs more effort (receipt, tracking, signature upon delivery), but you know it got there. In the networking world, UDP is the postcard and TCP is the registered letter.

The network layer (IP) delivers packets between machines — but it provides no guarantees. Packets can disappear, arrive out of order, or be duplicated. The transport layer sits on top of IP and offers two vastly different services to applications: UDP merely adds port numbers (so the right process receives the packet) and a simple checksum, but otherwise inherits IP's "best effort" delivery. TCP adds reliable delivery, ordering guarantees, flow control, and congestion control — everything IP lacks.

When is each used?

When you download a file, TCP is used because every single byte must arrive in the correct order. When you talk on Discord, UDP is used because it is more important that the audio arrives quickly than that every single audio packet arrives — a lost packet causes a small glitch, but a delayed packet makes the conversation unusable.

The chapter builds up layer by layer: first multiplexing and UDP (the simple part), then the principles of reliable data transfer (the rdt protocols), then TCP with everything it entails, and finally congestion control — the mechanisms that prevent the Internet from collapsing under its own traffic.

Test yourself

Check whether you have understood the most important concepts from this chapter.

Question 1 · Easy
Which statement best describes transport-layer multiplexing and demultiplexing?
Port numbers are used to deliver data to the correct process on the correct host.
Question 2 · Medium
In practice, which statement about the UDP header size is most correct?
The UDP header is 8 bytes, giving low protocol overhead.
Question 3 · Hard
In a larger network setting, which evaluation of the limitation of simple checksum error detection is most accurate?
Checksums detect many errors, but can rarely miss certain bit patterns.
Question 4 · Medium
In practice, which statement about stop-and-wait transmission is most correct?
Stop-and-wait allows only one outstanding packet before the sender waits for an ACK.
Question 5 · Easy
Which statement best describes why pipelining improves efficiency?
Pipelining keeps multiple packets in flight and reduces idle time between RTTs.
Question 6 · Hard
In a larger network setting, which evaluation of Go-Back-N behavior on loss is most accurate?
Go-Back-N retransmits the lost packet and all subsequent packets in the window.
Question 7 · Medium
In practice, which statement about Selective Repeat behavior on loss is most correct?
Selective Repeat retransmits only missing packets and buffers the rest.
Question 8 · Hard
In a larger network setting, which evaluation of sequence numbers in reliable transfer is most accurate?
Sequence numbers allow duplicate detection and correct ordering at the receiver.
Question 9 · Easy
Which statement best describes cumulative ACKs in TCP?
An ACK number confirms that all bytes before that number were received correctly.
Question 10 · Hard
In a larger network setting, which evaluation of the TCP three-way handshake is most accurate?
The three-way handshake synchronizes sequence numbers and establishes state at both ends.
Question 11 · Medium
In practice, which statement about flow control with rwnd is most correct?
The receiver advertises rwnd to prevent the sender from overrunning the receive buffer.
Question 12 · Hard
In a larger network setting, which evaluation of congestion control with cwnd is most accurate?
The sender limits its send window with cwnd to avoid overloading the network.
Question 13 · Easy
Which statement best describes slow start?
In slow start, cwnd grows roughly exponentially, typically doubling per RTT.
Question 14 · Medium
In practice, which statement about congestion avoidance is most correct?
In congestion avoidance, cwnd increases linearly, about 1 MSS per RTT.
Question 15 · Hard
In a larger network setting, which evaluation of the AIMD principle is most accurate?
TCP uses additive increase and multiplicative decrease for stable and fair sharing.
Question 16 · Medium
In practice, which statement about response to timeout in classic TCP Reno is most correct?
On timeout, cwnd is reduced sharply and the connection returns to cautious startup behavior.
Question 17 · Easy
Which statement best describes three duplicate ACKs?
Three duplicate ACKs are treated as likely loss and trigger fast retransmit before timeout.
Question 18 · Hard
In a larger network setting, which evaluation of fast recovery in Reno is most accurate?
Reno keeps data flowing after fast retransmit instead of restarting from scratch.
Question 19 · Medium
In practice, which statement about the relation between MTU and MSS is most correct?
MSS is the TCP payload size that avoids IP fragmentation for the current MTU.
Question 20 · Hard
In a larger network setting, which evaluation of RTT estimation in TCP is most accurate?
TCP uses smoothed RTT and variance to set a robust retransmission timer.
Question 21 · Medium
In practice, which statement about TCP sequence numbers are byte-oriented is most correct?
The sequence number identifies the first payload byte in the segment, not a packet counter.
Question 22 · Hard
In a larger network setting, which evaluation of head-of-line blocking in TCP is most accurate?
Loss of one segment can block delivery of later data even if they have already arrived.
Question 23 · Easy
Which statement best describes why QUIC reduces HOL problems?
QUIC uses independent streams so loss in one stream does not block all others.
Question 24 · Medium
In practice, which statement about well-known and ephemeral ports is most correct?
Servers often listen on well-known ports, while clients use temporary ephemeral ports.
Question 25 · Hard
In a larger network setting, which evaluation of the pseudo-header in transport checksums is most accurate?
The pseudo-header binds the checksum to IP addresses and protocol fields for extra protection.
