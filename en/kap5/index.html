The Network Layer:
The Control Plane

In chapter 4 we saw how a single router moves packets from input to output — the data plane. But who decides which output is correct? That is the control plane's job: to ensure that thousands of routers agree on the path, so that your packet actually arrives.

Overview

The GPS inside the network

The control plane is the invisible brain that computes the route — before the data plane lifts a single packet.

Think of it this way: you are sitting in a car and need to get from Trondheim to Bergen. The data plane is the car itself — the steering wheel, the pedals, the engine that physically moves you along the road. But the car alone is useless without a plan for which road to take. The control plane is the GPS. It gathers maps of all the roads, computes the best route, and tells the car at each intersection: "turn left here." Without the GPS, the car would just idle at every intersection, not knowing which direction to go.

In a real network, this is even more impressive. There is not just one GPS sitting on top and controlling everything. In the traditional Internet, every single router runs its own GPS computation. They talk to their neighboring routers, exchange information about which destinations they can reach and what it costs, and gradually — through routing algorithms — all agree on a consistent forwarding table. The alternative is SDN (Software Defined Networking), where one central controller acts as a super-GPS that computes the route for everyone and pushes the tables down to the routers.

When you send a message on Snapchat, it may need to pass through 15 routers. The control plane is what ensures that all of these routers agree on the path — before your message even leaves your phone. If just one router disagrees, the packet can end up in a loop, disappear, or take a detour via Tokyo.

But what happens when something goes wrong along the way — a router crashes, a link goes down, or a packet wanders in circles? Then the network needs a signaling language to report the problem. That is where ICMP (Internet Control Message Protocol) comes in: a small, humble protocol that lets routers and hosts shout "error!" or "are you there?" to each other. It is also the engine behind tools like ping and traceroute — the tools you use to troubleshoot networks in the real world.

The interplay between the two planes is the core of everything we cover in this chapter. The control plane can be organized in two ways: per-router control, where each router independently runs its own routing algorithm (how the Internet works today), or centralized control (SDN), where one controller computes everything and pushes the tables out. In addition, ICMP gives the network a signaling language for error messages — and gives us tools like traceroute to see exactly which path the packets take.

Test yourself

Check whether you have understood the most important concepts from this chapter.

Question 1 · Easy
Which statement best describes what the control plane does?
Correct. The control plane computes routes and populates forwarding tables used by the data plane.
Question 2 · Medium
In practice, which statement about the link-state principle is most correct?
Correct. In link-state, routers know the full topology and compute shortest paths locally.
Question 3 · Hard
In a larger network setting, which evaluation of Dijkstra in routing is most accurate?
Correct. Dijkstra builds a shortest-path tree from one source given known link costs.
Question 4 · Medium
In practice, which statement about the distance-vector principle is most correct?
Correct. Distance-vector exchanges cost estimates neighbor-to-neighbor and updates iteratively.
Question 5 · Easy
Which statement best describes Bellman-Ford in DV?
Correct. Bellman-Ford updates best routes by minimizing over neighbors' advertised costs.
Question 6 · Hard
In a larger network setting, which evaluation of the count-to-infinity problem is most accurate?
Correct. In DV, incorrect reachability info can persist and metrics can climb gradually.
Question 7 · Medium
In practice, which statement about poison reverse is most correct?
Correct. Poison reverse advertises infinity back to the neighbor that supplied a route to mitigate simple loops.
Question 8 · Hard
In a larger network setting, which evaluation of convergence in routing protocols is most accurate?
Correct. Fast, stable convergence reduces periods of loss, loops, and suboptimal routing.
Question 9 · Easy
Which statement best describes OSPF?
Correct. OSPF is a link-state IGP using cost metrics and LSA flooding.
Question 10 · Hard
In a larger network setting, which evaluation of RIP is most accurate?
Correct. RIP is a simple distance-vector protocol using hop count as metric.
Question 11 · Medium
In practice, which statement about BGP as the inter-AS protocol is most correct?
Correct. BGP advertises AS paths and policy attributes between autonomous systems.
Question 12 · Hard
In a larger network setting, which evaluation of policy in BGP is most accurate?
Correct. BGP often selects routes by business policy and economics, not only shortest path.
Question 13 · Easy
Which statement best describes eBGP versus iBGP?
Correct. eBGP runs between ASes, while iBGP distributes external routes inside an AS.
Question 14 · Medium
In practice, which statement about an SDN controller is most correct?
Correct. In SDN, control logic moves to a logically centralized controller that programs network devices.
Question 15 · Hard
In a larger network setting, which evaluation of match-action tables is most accurate?
Correct. Match-action rules determine packet handling based on header fields.
Question 16 · Medium
In practice, which statement about an OpenFlow-like southbound API is most correct?
Correct. A southbound interface lets the controller install and update rules in switches/routers.
Question 17 · Easy
Which statement best describes data plane versus control plane?
Correct. The data plane forwards packets, while the control plane computes the rules it follows.
Question 18 · Hard
In a larger network setting, which evaluation of ping and ICMP echo is most accurate?
Correct. Ping tests reachability by sending ICMP echo requests and timing echo replies.
Question 19 · Medium
In practice, which statement about traceroute and TTL is most correct?
Correct. Traceroute uses increasing TTL values to elicit replies from each hop along the path.
Question 20 · Hard
In a larger network setting, which evaluation of flooding of link-state advertisements is most accurate?
Correct. Flooding distributes topology changes quickly so all routers can recompute consistently.
Question 21 · Medium
In practice, which statement about LSA sequence numbers is most correct?
Correct. Sequence numbers and age prevent stale link-state messages from overriding fresh ones.
Question 22 · Hard
In a larger network setting, which evaluation of hierarchical routing is most accurate?
Correct. Hierarchy improves control-plane scalability by dividing networks into administrative regions.
Question 23 · Easy
Which statement best describes hot-potato routing?
Correct. An AS often exits traffic at the nearest egress to minimize internal transport cost.
Question 24 · Medium
In practice, which statement about routing instability is most correct?
Correct. Conflicting policies and rapid changes can cause oscillations and temporary route instability.
Question 25 · Hard
In a larger network setting, which evaluation of fast failure response in the control plane is most accurate?
Correct. Fast failure detection and reconvergence reduce downtime and packet loss.
