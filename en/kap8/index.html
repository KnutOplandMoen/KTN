Overview

The big picture

Network security is about protecting data traveling through a network full of potential attackers — using four tools that each solve one specific problem.

In the textbook (Sec. 8.1), the CIA triad is a common frame: Confidentiality (only authorized parties can read content), Integrity (content is authentic and unaltered), and Availability (services are reachable for legitimate users). The four properties used in this chapter (confidentiality, authentication, message integrity, availability) align with CIA: authentication and integrity especially support the I dimension, while denial-of-service (DoS) attacks mainly target the A dimension.

Imagine you need to send a valuable diamond through a postal system full of thieves. You need: (1) a locked box that only the recipient can open (encryption), (2) a seal that shows if someone has opened the box en route (integrity / MAC), (3) a way to prove that it really is you who sent it (authentication / digital signatures), and (4) guards at the door who inspect every single package (firewalls). Each security tool solves one specific problem.

Real-world example

When you see the padlock in your browser on ntnu.no, it means TLS is active. The browser and server have completed a handshake where they agreed on encryption keys — and now everything you send is encrypted so that no one on the WiFi network can read it.

The toolbox — four layers of security

Symmetric encryption (e.g. AES) — fast, but requires both parties to share the same secret key.

Public key cryptography — solves key distribution and digital signatures; the curriculum omits detailed RSA derivations, but the key-pair idea is central to TLS and secure email.

Message integrity and digital signatures (including HMAC and hash-plus-signature) — ensures content is unaltered and the sender can be verified.

Firewalls (Sec. 8.9.1) — stateless and stateful packet filtering, application gateways, and ACL rules that control which traffic is allowed through.

Test yourself

Check whether you have understood the most important concepts from this chapter.

Question 1 · Easy
Which statement best describes the CIA triad?
Confidentiality, integrity, and availability are the foundational goals of information security.
Question 2 · Medium
In practice, which statement about symmetric encryption is most correct?
Symmetric encryption is fast and suitable for bulk data with a shared secret key.
Question 3 · Hard
In a larger network setting, which evaluation of asymmetric encryption is most accurate?
Asymmetric cryptography uses key pairs and is useful for key exchange and signatures.
Question 4 · Medium
In practice, which statement about hybrid encryption is most correct?
Hybrid schemes use asymmetric methods for key exchange and symmetric methods for data encryption.
Question 5 · Easy
Which statement best describes AES?
AES is a symmetric block cipher used widely in modern protocols.
Question 6 · Hard
In a larger network setting, which evaluation of RSA/ECC keys is most accurate?
The private key remains secret, while the public key can be shared for verification and key agreement.
Question 7 · Medium
In practice, which statement about hash functions is most correct?
A cryptographic hash gives a short fingerprint that changes dramatically with tiny input changes.
Question 8 · Hard
In a larger network setting, which evaluation of a Message Authentication Code (MAC) is most accurate?
A MAC provides integrity and authentication between parties sharing a secret key.
Question 9 · Easy
Which statement best describes digital signatures?
Digital signatures provide verifiable sender authentication and non-repudiation.
Question 10 · Hard
In a larger network setting, which evaluation of certificates and CAs is most accurate?
A certificate binds identity to a public key through a signature from a trusted CA.
Question 11 · Medium
In practice, which statement about the TLS handshake is most correct?
The TLS handshake establishes crypto parameters and shared session keys before application data is sent.
Question 12 · Hard
In a larger network setting, which evaluation of session keys is most accurate?
Session keys are short-lived keys used for efficient encryption of one connection.
Question 13 · Easy
Which statement best describes Perfect Forward Secrecy?
PFS ensures compromise of long-term keys does not reveal past sessions.
Question 14 · Medium
In practice, which statement about salted password hashes is most correct?
Salts prevent equal passwords from producing equal hashes and weaken precomputed-table attacks.
Question 15 · Hard
In a larger network setting, which evaluation of stateless packet filtering is most accurate?
Stateless filtering matches packets against rules without flow history context.
Question 16 · Medium
In practice, which statement about stateful firewalls is most correct?
A stateful firewall tracks connection state and can dynamically permit return traffic.
Question 17 · Easy
Which statement best describes IDS versus IPS?
IDS detects and alerts, while IPS can actively block suspicious traffic.
Question 18 · Hard
In a larger network setting, which evaluation of the DDoS mechanism is most accurate?
DDoS uses many distributed sources to overload targets and make filtering harder.
Question 19 · Medium
In practice, which statement about phishing is most correct?
Phishing manipulates users into revealing secrets via convincing but fake messages/sites.
Question 20 · Hard
In a larger network setting, which evaluation of man-in-the-middle attacks is most accurate?
MITM places an attacker in the traffic path for eavesdropping, modification, or injection.
Question 21 · Medium
In practice, which statement about replay attacks is most correct?
Replay attacks reuse valid messages later to trick systems into accepting stale actions.
Question 22 · Hard
In a larger network setting, which evaluation of nonces and timestamps is most accurate?
Unique nonces/timestamps provide freshness and reduce replay risk.
Question 23 · Easy
Which statement best describes DNS spoofing?
DNS spoofing tries to make clients resolve wrong IPs and contact attacker-controlled targets.
Question 24 · Medium
In practice, which statement about least privilege is most correct?
Least privilege restricts access to what is necessary and limits blast radius on compromise.
Question 25 · Hard
In a larger network setting, which evaluation of defense in depth is most accurate?
Multiple independent security layers keep systems resilient even if one control fails.
