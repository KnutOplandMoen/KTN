Chapter 6 · The Link Layer

The Link Layer and LANs

The final leg of the journey down the protocol stack. Here we encounter the actual cables, frames, and addresses that ultimately carry bits from one machine to another.

  1. 01Big Picture
  2. 02Sections
  3. 03Test Yourself
Overview

The Big Picture

The link layer is the final leg — what actually gets bits from one machine to its neighbor over a physical link. Everything above (IP, TCP, HTTP) blindly trusts that this works.

Analogy — the postal system, the last meter

If the network layer (IP) is like addressing a letter with a postal code for the right city, the link layer is the local mail carrier who knows every house on the street. MAC addresses are like the house number on a specific street — they only have local significance. When a packet arrives at your local network, IP has gotten it to the right "neighborhood" (subnet), but it is Ethernet and ARP that find the specific machine. It is "the last meter" of the delivery.

Analogy — the busy office

Imagine a busy office with one shared printer cable. Everyone wants to print at the same time. CSMA/CD is the rules they follow: listen before you send (carrier sense), don't send if someone else is sending (collision avoidance), and if two send simultaneously, both stop, wait a random time, and try again (collision detection + exponential backoff). Ethernet uses exactly this logic.

In practice — right in front of you

When your laptop sends a packet to the router at home, it uses Ethernet (via WiFi or cable). It needs the router's MAC address — and uses ARP to find it. The laptop sends a broadcast: "Who has IP 192.168.1.1?" The router replies with its MAC address. All of this happens automatically, without you noticing, every time you open a web page.

Test yourself

Question 1 · Easy
Which statement best describes link-layer framing?
The link layer encapsulates network-layer packets into frames with local address and control fields.
Question 2 · Medium
In practice, which statement about medium access on a shared channel is most correct?
MAC protocols determine who may transmit when multiple nodes share the medium.
Question 3 · Hard
In a larger network setting, which evaluation of CRC error detection is most accurate?
CRC detects single-bit and many burst errors with high probability.
Question 4 · Medium
In practice, which statement about MAC addresses is most correct?
MAC addresses are 48-bit identifiers used for local link delivery.
Question 5 · Easy
Which statement best describes an ARP request?
An ARP request is broadcast when the sender lacks the destination MAC address.
Question 6 · Hard
In a larger network setting, which evaluation of a switch learning table is most accurate?
A switch learns source-MAC-to-port mappings by observing incoming frames.
Question 7 · Medium
In practice, which statement about flooding for unknown destinations is most correct?
When destination MAC is unknown, the switch floods the frame out all other ports.
Question 8 · Hard
In a larger network setting, which evaluation of a hub versus a switch is most accurate?
A hub repeats signals to all ports, while a switch forwards selectively.
Question 9 · Easy
Which statement best describes collision domains?
Switches split collision domains per port, increasing effective capacity.
Question 10 · Hard
In a larger network setting, which evaluation of CSMA/CD is most accurate?
CSMA/CD senses before transmit, detects collisions, stops, and retries later.
Question 11 · Medium
In practice, which statement about the jam signal on Ethernet collision is most correct?
The jam signal informs other nodes of the collision so all transmitters abort.
Question 12 · Hard
In a larger network setting, which evaluation of binary exponential backoff is most accurate?
After each collision, waiting time is chosen from a growing random window to spread retries.
Question 13 · Easy
Which statement best describes the minimum Ethernet frame size?
A 64-byte minimum ensures collisions can be detected before a frame finishes transmission.
Question 14 · Medium
In practice, which statement about full-duplex Ethernet is most correct?
In full-duplex point-to-point Ethernet, collisions do not occur, so CSMA/CD is unnecessary.
Question 15 · Hard
In a larger network setting, which evaluation of VLANs is most accurate?
VLANs divide one physical switched network into multiple logical broadcast domains.
Question 16 · Medium
In practice, which statement about why WiFi uses CSMA/CA is most correct?
WiFi cannot reliably detect collisions while transmitting and therefore tries to avoid them.
Question 17 · Easy
Which statement best describes 802.11 link-layer ACKs?
WiFi uses link-layer ACKs and retransmissions to handle higher radio error rates.
Question 18 · Hard
In a larger network setting, which evaluation of slotted ALOHA efficiency is most accurate?
Maximum throughput fraction for slotted ALOHA is 1/e under ideal assumptions.
Question 19 · Medium
In practice, which statement about pure ALOHA efficiency is most correct?
Pure ALOHA has lower maximum efficiency (1/2e) than slotted ALOHA.
Question 20 · Hard
In a larger network setting, which evaluation of the broadcast MAC address is most accurate?
ff:ff:ff:ff:ff:ff means the frame should be delivered to all nodes on the local link.
Question 21 · Medium
In practice, which statement about switch table aging is most correct?
Learned MAC entries age out after inactivity to handle topology changes.
Question 22 · Hard
In a larger network setting, which evaluation of Spanning Tree in Ethernet is most accurate?
Spanning Tree logically blocks selected links to prevent layer-2 loops.
Question 23 · Easy
Which statement best describes Ethernet frame fields?
An Ethernet frame includes destination, source, type/length, payload, and FCS.
Question 24 · Medium
In practice, which statement about Ethernet MTU is most correct?
Standard Ethernet MTU is typically 1500 bytes of IP payload before fragmentation is considered.
Question 25 · Hard
In a larger network setting, which evaluation of local retransmission at the link layer is most accurate?
Link-layer retransmissions can hide some losses from transport and improve perceived performance.
