Chapter 6 · The Link Layer

The Link Layer and LANs

The final leg of the journey down the protocol stack. Here we encounter the actual cables, frames, and addresses that ultimately carry bits from one machine to another.

Overview

The Big Picture

The link layer is the final leg — what actually gets bits from one machine to its neighbor over a physical link. Everything above (IP, TCP, HTTP) blindly trusts that this works.

Analogy — the postal system, the last meter

If the network layer (IP) is like addressing a letter with a postal code for the right city, the link layer is the local mail carrier who knows every house on the street. MAC addresses are like the house number on a specific street — they only have local significance. When a packet arrives at your local network, IP has gotten it to the right "neighborhood" (subnet), but it is Ethernet and ARP that find the specific machine. It is "the last meter" of the delivery.

Analogy — the busy office

Imagine a busy office with one shared printer cable. Everyone wants to print at the same time. CSMA/CD is the rules they follow: listen before you send (carrier sense), don't send if someone else is sending (collision avoidance), and if two send simultaneously, both stop, wait a random time, and try again (collision detection + exponential backoff). Ethernet uses exactly this logic.

In practice — right in front of you

When your laptop sends a packet to the router at home, it uses Ethernet (via WiFi or cable). It needs the router's MAC address — and uses ARP to find it. The laptop sends a broadcast: "Who has IP 192.168.1.1?" The router replies with its MAC address. All of this happens automatically, without you noticing, every time you open a web page.

Test Yourself

Quick Quiz

Question 1
Host A wants to send an IP packet to Host B on the same local network (LAN). A knows B's IP address but has no entry for B in its ARP cache. What happens?
Correct! The Ethernet frame needs a MAC address as the destination — not an IP address. When the ARP cache is empty, A sends an ARP request as a broadcast (FF-FF-FF-FF-FF-FF). B recognizes its own IP and replies with its MAC address. Only then can A send the actual IP packet encapsulated in an Ethernet frame addressed to B's MAC.
Question 2
What is the most important difference between a MAC address and an IP address?
Correct! The MAC address (48 bits) is "burned in" to the network interface card and follows the device no matter where it connects. The IP address is logical — it changes when you switch networks. Routers use IP to find the path across the internet; MAC addresses are only used on the local link to identify the neighbor.
Question 3
In CSMA/CD: what does a station do when it detects a collision while transmitting?
Correct! Upon collision, the station stops immediately, sends a short jam signal so that everyone knows a collision occurred, and then waits a random time. The waiting time is chosen using binary exponential backoff: after the n-th collision, the waiting time is chosen randomly from {0, 1, …, 2ⁿ−1} time slots. This spreads out the attempts and reduces the chance of another collision.
