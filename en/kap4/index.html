The Network Layer

How a packet actually finds its way from your machine to a server on the other side of the globe — and everything that happens inside the routers along the way.

  1. 01Overview
  2. 02Parts
  3. 03Test yourself
Overview

The big picture

The network layer data plane is about one thing: when a packet lands on a router, how does it find the correct output — in nanoseconds?

Think of the Internet as an enormous highway system. Each router is an intersection, and the forwarding table is the road signs. When a packet arrives at a router, it reads the destination IP (like reading a road sign), looks it up in the forwarding table (like checking the directional signs), and sends the packet out the correct port (takes the right exit). IP addresses function like postal codes — the CIDR prefix tells you the region, and the host part is the specific house.

★ A real-world example

When your packet travels from Trondheim to a Netflix server in Amsterdam, it may pass through 12 routers. At each router, the same thing happens: read the destination IP, look it up in the table, forward the packet. The entire process takes nanoseconds. What makes this possible is that the network layer data plane is extremely simple — match an address, choose a port, done. All the complexity (routing algorithms, BGP, OSPF) lives in the control plane, which runs in the background.

In this chapter we look at what happens inside the router: the architecture of input ports, switching fabric and output ports; longest prefix match for selecting the correct route; queues and scheduling when there is congestion; and then the IP protocol itself — the datagram format, CIDR addressing, DHCP, NAT and IPv6.

Test yourself

Check whether you have understood the most important concepts from this chapter.

Question 1 · Easy
Which statement best describes data-plane forwarding?
Forwarding is the fast per-packet operation that sends a packet to the correct output port.
Question 2 · Medium
In practice, which statement about longest-prefix matching is most correct?
When multiple routes match, the one with the longest, most specific prefix is selected.
Question 3 · Hard
In a larger network setting, which evaluation of CIDR prefixes is most accurate?
CIDR expresses networks as address/prefix-length and enables flexible address allocation.
Question 4 · Medium
In practice, which statement about the default route is most correct?
The default route is used when no more specific entry matches the destination address.
Question 5 · Easy
Which statement best describes subnet masks?
A subnet mask separates the network part from the host part of an IPv4 address.
Question 6 · Hard
In a larger network setting, which evaluation of a host sending to another subnet is most accurate?
The host sends the frame to the default gateway when the destination is outside its subnet.
Question 7 · Medium
In practice, which statement about ARP resolution is most correct?
ARP maps a local IP address to a local MAC address on the same link.
Question 8 · Hard
In a larger network setting, which evaluation of the DHCP DORA sequence is most accurate?
A typical DHCP flow is Discover, Offer, Request, and Ack.
Question 9 · Easy
Which statement best describes NAT with port translation?
NAT maps many internal addresses to one public address using port numbers.
Question 10 · Hard
In a larger network setting, which evaluation of private IPv4 addresses is most accurate?
Private addresses are not globally routable and are used behind NAT in local networks.
Question 11 · Medium
In practice, which statement about the IPv4 TTL field is most correct?
TTL is decremented per hop to prevent packets from looping forever during routing failures.
Question 12 · Hard
In a larger network setting, which evaluation of the IPv4 header checksum is most accurate?
The IPv4 header checksum must be recomputed at each router because header fields like TTL change.
Question 13 · Easy
Which statement best describes IP fragmentation?
If a datagram exceeds link MTU and DF=0, it may be fragmented into multiple pieces.
Question 14 · Medium
In practice, which statement about the DF bit set to 1 is most correct?
With DF=1, oversized packets are dropped, and the sender typically must reduce packet size.
Question 15 · Hard
In a larger network setting, which evaluation of the fixed IPv6 header is most accurate?
IPv6 uses a fixed 40-byte base header, simplifying fast forwarding.
Question 16 · Medium
In practice, which statement about why IPv6 removed the header checksum is most correct?
IPv6 removed the header checksum to reduce per-hop work since other layers already provide error checks.
Question 17 · Easy
Which statement best describes router output queues?
When the outgoing link is saturated, queues build up; if buffers fill, packets must be dropped.
Question 18 · Hard
In a larger network setting, which evaluation of forwarding-table lookups is most accurate?
The router performs prefix lookup on destination address to choose the next hop.
Question 19 · Medium
In practice, which statement about the switching fabric inside a router is most correct?
The switching fabric moves packets from selected input ports to selected output ports inside the router.
Question 20 · Hard
In a larger network setting, which evaluation of route aggregation is most accurate?
Aggregation combines prefixes to reduce table size and control-plane load.
Question 21 · Medium
In practice, which statement about best-effort in IP is most correct?
IP does not guarantee delivery, ordering, or bandwidth; that is handled by end systems.
Question 22 · Hard
In a larger network setting, which evaluation of how MAC addresses change hop-by-hop is most accurate?
MAC addresses are link-local and change each hop, while the IP destination remains end-to-end.
Question 23 · Easy
Which statement best describes NAT and incoming connections?
NAT hides internal hosts and requires port forwarding or similar mechanisms for inbound access.
Question 24 · Medium
In practice, which statement about CIDR and variable subnetting is most correct?
CIDR allows subnet sizing to fit actual needs instead of fixed address classes.
Question 25 · Hard
In a larger network setting, which evaluation of when a default route is useful is most accurate?
Small networks often use a default route to send unknown traffic to an upstream router.
